# Case Finder

Создай серьёзный, официальный и современный веб-интерфейс для информационной системы розыска лиц, ориентированный на сотрудников правоохранительных и государственных органов.

ВАЖНО: это не копия сайта rozysk.caricc.org. Используй только общую концепцию информационной системы розыска, но полностью переработай UX/UI и визуальную подачу. Не копируй дизайн, логотипы, тексты, фирменный стиль или исходный код существующего сайта.

Главная цель — сделать интерфейс значительно удобнее, быстрее для работы с большими объёмами информации и визуально современнее, при этом сохранить ощущение официальной государственной системы.

## ВИЗУАЛЬНЫЙ СТИЛЬ

Стиль:
* официальный;
* строгий;
* современный;
* минималистичный;
* технологичный, но без "киберпанка";
* интерфейс должен выглядеть как реальная профессиональная государственная информационная система;
* никаких градиентов ради градиентов;
* никаких огромных декоративных элементов;
* никаких чрезмерно округлых карточек;
* никаких игровых элементов;
* никаких неуместных анимаций.

Цветовая палитра:
* основной фон: очень светлый серо-белый;
* основной текст: тёмно-синий/графитовый;
* акцент: глубокий синий;
* вторичный цвет: холодный серый;
* предупреждения: использовать только там, где действительно необходимо.

Типографика:
* Inter или аналогичный современный нейтральный шрифт;
* отличная читаемость;
* чёткая визуальная иерархия.

## ОСНОВНАЯ СТРАНИЦА

Сделай современный Dashboard.

Слева — компактный sidebar:
* Главная
* Поиск
* Расширенный поиск
* Результаты
* Избранное
* История поиска
* Справочная информация
* Настройки

Внизу sidebar:
* профиль пользователя;
* роль пользователя;
* кнопка выхода.

На верхней панели:
* название системы;
* строка глобального поиска;
* уведомления;
* профиль пользователя.

## DASHBOARD

После входа пользователь видит:
"Информационная система розыска"

Ниже небольшие статистические блоки:
* Всего записей
* Новые записи
* Обновлено сегодня
* Активные ориентировки

Не используй огромные цифры на весь экран. Это должна быть рабочая панель, а не рекламный сайт.

Ниже:
* последние поисковые запросы;
* недавно просмотренные записи;
* быстрые действия.

## ОСНОВНОЙ ПОИСК

Сделай поиск центральной функцией системы.
Большой, но компактный поисковый блок: "Поиск по базе"
Поля:
* Фамилия
* Имя
* Отчество
* Дата рождения
* Гражданство
* Пол
* Документ
* Инициатор розыска

Кнопки:
[ Найти ] [ Очистить ]

Рядом или ниже: "Расширенный поиск"
При открытии расширенного поиска появляются дополнительные параметры.

## UX ПОИСКА

Не заставляй пользователя каждый раз переходить на новую страницу. Поиск должен работать максимально быстро.
После выполнения запроса показывай результаты непосредственно под поисковой панелью.
Добавь:
* количество найденных результатов;
* фильтры;
* сортировку;
* пагинацию;
* возможность изменить параметры поиска без возврата назад.

Предусмотри состояния:
* поиск выполняется;
* ничего не найдено;
* ошибка запроса;
* найден один результат;
* найдено много результатов.

## РЕЗУЛЬТАТЫ

Переключатель: [ Таблица ] [ Карточки ]
По умолчанию — компактная таблица.
Колонки:
* Фото
* ФИО
* Дата рождения
* Гражданство
* Пол
* Инициатор
* Статус
* Действия

Каждая строка должна быть компактной. При клике на запись открывается подробная страница/side panel.

## ПРОФИЛЬ ЗАПИСИ И SIDE PANEL

Для быстрого просмотра записи используй выезжающую правую панель (Side Panel), чтобы просматривать несколько результатов подряд, не покидая страницу поиска.
Также предусмотри просмотр полной карточки записи с разделами: фото, основные идентификационные сведения, ФИО, дата рождения, гражданство, пол, документы, инициатор, статус, дата добавления и обновления.

## ИСТОРИЯ И ИЗБРАННОЕ

* Страница "История поиска" с параметрами запросов, датой и возможностью повторить поиск.
* Возможность добавления записей в "Избранное".

## ДЕМО-ДАННЫЕ И АДАПТИВНОСТЬ

* Реалистичные, но полностью вымышленные демонстрационные записи.
* Полная адаптивность (desktop, tablet, mobile с drawer-меню).
